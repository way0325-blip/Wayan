# 蝦皮店到店整合工作區

## 五個入口
1. 任務派車：既有車隊任務、LINE發布與報到、訂單合併及車趟調整，另以展開區放需求合計與車隊承接。
2. 路線清單：NB/FN/WB配送範本、一般/周六/周日上收、週期路線與倉庫核對。
3. 車行與群組：來源車行對照彙總、唯一車隊／LINE群組名冊、明確來源別名設定及承接能力明細。
4. 倉庫取貨點：倉別與實際取貨點、箱型、碼頭前綴、取貨點地址及原有地址編輯／參考地圖。
5. 資料匯入匯出：每日任務、訂單批次匯入、日期匯出、車行／週期來源、三類上收與N/F/W來源匯入。

既有控制項搬移至相應分頁，不複製輸入欄位及按鈕ID；事件及後端派車流程保留。來源名稱和LINE車隊仍須明確設定對應，區域倉和實際取貨點保留不同ID，不以同名合併資料。倉庫清單顯示正式取貨點地址，空白不猜測或沿用區域地址；查看任務可回到對應倉別篩選。

## API／資料表
新增 GET /api/weekly-routes/directory（管理員或調度登入），唯讀最新已匯入車行版本、不同路線數、待核對列數、明確對應的車隊ID與狀態。無資料表變更、無migration，不更動任何來源、訂單、車趟或群組綁定。

- public/shopeeIntegrated.js：五分頁、移動既有模組、來源車行彙總、倉庫取貨點整合表、捷徑與共用日期、權限及鍵盤操作。
- public/shopeeIntegrated.css：分頁與手機版排列。
- public/index.html：新增腳本及樣式。
- server/shopeeDirectory.js：唯讀車行／路線／名冊對應彙總。
- server/routes/weeklyRoutes.js：新增唯讀目錄API。
- server/tests/weekly-routes.test.js：目錄授權、不同路線統計、明確別名及無寫入驗證。
- scripts/verify-shopee-integrated.mjs：使用真正本機後端的介面整合測試。
- scripts/verify-weekly-routes.mjs：調整來源清單移至新分頁的斷言。

## 限制與風險
這是介面與查詢整合，不是刪除重複資料或自動合併資料主鍵。376筆附件匯入準備檔仍未寫入雲端，來源車行目錄以已匯入版本為準，22筆未填不推測。三個上收分頁真實內容仍待檔案提供。未自動發LINE、派車、寫入Google來源，正式環境及main不變。PR保留草稿。
尚未進行真人雲端登入後驗收、真實LINE收送或手機實機視覺驗收；響應式樣式與鍵盤導航已加入，不能宣稱所有裝置已驗收。
