# 取消新竹以北配送限制

2026-11-08；僅測試環境。

- 行政區選項及後端驗證改用全臺22縣市、368鄉鎮市區，不再限制新竹以北。包含宜蘭、中南部、花東與離島。
- 官方清單取自內政部國土測繪中心ListCounty及ListTown1 API，2026-11-08擷取，離線隨程式提供；執行時不依賴官方API可用性。資料來源：https://data.gov.tw/dataset/102011 ，政府資料開放授權條款第1版。
- 門店新增／匯入／縣市篩選、來源路線解析、每日預覽及來源建趟採相同清單。台北／台中／台南／台東縣市名稱正規化。
- 舊來源快照只在讀取時重新辨識地址及評估已移除的地理警告；不改寫原始JSON、digest、批次、歷史任務或來源Google檔案。即使不重新匯入，合法的外區路線也可使用。
- 完整地址／有效行政區、門店核對、箱型取貨點、日期、權限、交易、稽核、去重與其他異常檢核仍保留。不是取消所有安全或地址驗證。
- 地圖與畫面說明改為全臺參考範圍；行政區可選不表示已核實該區蝦皮門店或承運商服務。

API沿用原端點，config.regions擴充；無資料表變更、無migration、無刪除資料。相關後端66成功／0失敗；來源及畫面測試與CI結果見交付報告。正式環境、正式資料庫、main保持不變，不建立付費資源，不合併PR。
