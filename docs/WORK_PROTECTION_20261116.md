# 作業保護與00:00～23:59

使用者在操作時遭遇20～60秒輪詢及SSE事件重畫清單，且每日需求每勾一筆就重新render整個車隊內容。新增viewUpdates延後佇列，背景來源同步繼續；操作清單只顯示背景資料待套用，按「完成操作後更新畫面」才刷新。相同清單事件合併、不重複排隊。開啟編輯視窗時禁止套用；失敗可重試，登出清除佇列及舊回覆。

每日需求個別勾選／全選改為更新選取狀態，不重畫DOM。保留車隊展開狀態與有效勾選；手動套用後保留展開內容。後端來源版本變更仍沿用原有版本／權限驗證，過期選擇不自行強制保存。

派車、車隊名冊、週期及包時、出勤、路線與規則等破壞性清單刷新改走待套用佇列；不再因傳送工作／設定狀態的無關事件重畫訂單。儀表板數字持續更新，LINE對話在未操作時保留更新，操作中延後。統一同步按鈕可先同步來源；編輯視窗尚開啟時不重畫操作畫面。午夜切日遇操作中也延後，手選日期保持。

時間顯示與Google每日鏡像改為當日00:00～23:59；有效分鐘含23:59，不含隔日00:00。無API、資料表或migration變更，不改既有任務日期，不發送LINE。

新增public/viewUpdates.js、server/tests/view-updates.test.js；修改清單詳見交付報告。純佇列6項測試包含合併、編輯阻擋、中途新事件、失敗重試、同時套用及登出隔離；操作DOM15斷言以5輪timer/SSE驗證表單草稿、勾選、展開不變且按鈕可一次更新。每日任務UI13及統一同步UI15通過。完整lint與CI執行後記錄。

風險：清單不再自動重畫，需按提示套用新資料；儲存仍由後端檢查最新版本，可能需要重新核對衝突。正式環境維持不變、PR不自行合併。
