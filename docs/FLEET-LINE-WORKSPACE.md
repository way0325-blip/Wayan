# 車隊 LINE 工作區

夥伴車隊營運頁頂部提供車隊名冊／LINE 綁定、管理員群組清單、各車隊 LINE 動態的定位入口。綁定仍使用現有後端管理員授權；調度人員只顯示可用的狀態與動態入口。整頁重新整理也會更新動態。

本機（127.0.0.1／localhost）會明示資料來源，並提供已驗收的獨立 LINE 雲端測試平台連結。LINE Webhook 綁定至雲端測試服務時，本機資料庫不會自動同步該服務的群組及訊息。雲端平台仍須使用有權限的帳號登入，不會傳遞本機 Token 或密碼。

沒有新增 API、環境變數、資料表或 migration；繼續使用 /api/fleet-ops/fleets、groups、activity-status、activity 等既有受保護 API。頁面版本參數更新可避免沿用舊的動態與車隊腳本快取。正式設定、Webhook、資料與權限均不變。

風險與限制：本機及雲端是兩個獨立資料來源，連結不代表資料已合併。免費雲端服務可能冷啟動；管理員需在雲端登入後管理實際群組。圖片、語音與貼圖依既有功能只顯示事件類型。
