# 規則覆核、蝦皮總車數與 LINE 群組清單

本次僅供本機與獨立 staging 驗收；無 main 修改、PR 合併或正式部署。

## 操作

1. 夥伴車隊營運 → LINE 群組清單：管理員可登記群組名稱、Group ID，每次最多100筆。Group ID 為 C 開頭的33碼，不是邀請網址。Bot 收到通過簽章驗證的群組事件會自動收錄；群組名稱由管理員登記，不猜測名稱。
2. 邀請既有測試 Bot 到群組，傳送訊息後，新增／編輯車隊可選擇已驗證且未綁定的群組。一群組對應一車隊；一車隊對應一群組。選擇與車隊存檔在同一資料庫交易內。亦保留既有一次性綁定碼流程。
3. 群組清單顯示 Bot 最近事件狀態、最後接收時間、綁定車隊、累積失敗事件與通知數。這是最近收到的事件證據，不是持續探測 LINE 在線狀態；沒有最近事件不表示 Bot 離線。收到 leave 事件立即解除綁定，保留歷程。
4. 蝦皮車隊需求 → 夥伴車隊：依作業日期顯示各車隊要求趟數、已承接、累計已報到總車數、待報到與最後回報。各路線仍分別列出要求／承接趟數，報到只採車隊每日總數，不虛構分路線到場數或不重複車牌數。
5. LINE 指令：`蝦皮任務`、`蝦皮承接 S任務編號 趟數`、`蝦皮拒絕 S任務編號 原因`、`蝦皮報到 累計總車數`。例如先回報2、後回報5，總數是5，不是7。相同數字與相同事件重送不重複計數。只能回報台灣時間今日且有已確認承接的任務；不能超過車隊當日承接總量。
6. 管理員可填寫原因更正較低總數；調度可補登增加的總數。回報歷程追加保存，不刪除舊數字。降低承接量不得低於累計報到；已有回報歷程的路線／分派不可刪除。
7. 罰款規則管理：版本、條款、來源、0.01精度點數、參考金額、生效日、草稿／已核實／已停用與覆核歷程。條款不可原地覆寫，修訂新增版本。生效日未知可留空，但不能用來確認個案。
8. 人工罰款案件：已核實且已知生效日的規則才可立案；初始不帶入點數或金額。管理員需人工填點數、金額、責任與結論。已確認可提出申訴，由管理員維持或撤銷；所有操作保留歷程。沒有扣薪、扣款或對外收款功能。

## API

所有管理端 API 均需登入及 admin／dispatcher。群組清單、匯入與綁定、規則新增與核實、案件確認／撤銷限 admin。LINE 使用既有原始本文簽章、持久事件去重與群組範圍授權。

| 方法 | API | 用途 |
|---|---|---|
| GET | /api/fleet-ops/groups | 群組清單與事件狀態 |
| POST | /api/fleet-ops/groups/import | 原子批次登記名稱與 Group ID |
| POST | /api/fleet-ops/fleets/:id/group | 選擇已驗證群組 |
| GET | /api/shopee-live?date=YYYY-MM-DD | 車隊需求與累計報到，同一快照 |
| GET/POST | /api/shopee-live/fleets/:id/reports | 歷程／人工登記累計總數 |
| POST | /api/shopee-live/:id/notify | 蝦皮任務排入 LINE 通知 |
| GET/POST | /api/penalty-rules | 規則版本清單／草稿 |
| GET | /api/penalty-rules/:id/history | 規則覆核歷程 |
| POST | /api/penalty-rules/:id/review | 核實或停用 |
| GET/POST | /api/penalty-cases | 個案清單／人工立案 |
| GET | /api/penalty-cases/:id/history | 案件歷程 |
| POST | /api/penalty-cases/:id/review | 管理員確認／撤銷 |
| POST | /api/penalty-cases/:id/appeal | 提出申訴 |

## 資料庫與同步

增量 migration 003 新增 penalty_rules、penalty_rule_history、penalty_cases、penalty_case_history、shopee_fleet_reports、line_group_registry。擴充 fleet_sheet_rows 的允許類別，不刪除既有表或欄位。DB 交易同步保存操作稽核與同步工作；案例／規則／歷程由觸發器排入 outbox。LINE 通知優先於 Sheets 工作，沿用固定重試鍵與23小時安全重試限制。

Google Sheets 新增「罰款記點規則」「罰款記點案件」「罰款處理歷程」，沿用固定資料列、RAW寫入、防重複與防錯列。規則與案件狀態照實同步；申訴中的點數與金額是前次確認值，不能當成最終應收金額。完整重送涵蓋新增三類紀錄。背景授權仍需專用測試寫入帳號，Drive插件授權不會自動交給Node伺服器。

PDF原件、影像、私人條款草稿與雲端試算表識別資料留在本機工作目錄，不納入公開專案。通用匯入器 server/importRuleDrafts.js 只接受外部提供的草稿資料；不替條款核實、設定生效日或自動計罰。

## 邊界與待驗收

- LINE群組所有成員均視為該車隊受信任回報人；尚無個別成員職務白名單。不得綁定包含無關人員的群組。
- 累計報到採接收順序，沒有車牌、個人出勤或GPS到場驗證。報到單位須由營運確認為與當日承接趟數相同的計數單位。
- 即時更新使用既有登入SSE，斷線每30秒補查；受本機服務、網路、LINE傳遞與背景工作排程影響，不保證零延遲。
- 草稿來源為掃描PDF人工轉錄，需主管逐條核對。累犯階梯、按箱、不認列運費、賠償、停線等條件僅保留文字，沒有自動計算／執行。
- 本機之外的 HTTPS 測試端點與真實 LINE 群組回報尚未驗收；提供的 Render URL 未使用。手機、桌面、列印等實際瀏覽器驗收須另行完成。
