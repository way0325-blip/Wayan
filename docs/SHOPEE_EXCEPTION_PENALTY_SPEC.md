# 蝦皮車隊異常案件、溝通與雙向罰款管理規格

狀態：需求規格 v1.0；尚未實作程式或部署。
分支：feature/shopee-exception-penalty

## 1. 目的與原則
每件異常均建立唯一案件，完整追蹤發生、回報、證據、內外部溝通、責任判定、罰款、申訴及結案。
- 一案可關聯多筆車趟、多筆溝通、多份附件及多筆罰款。
- 支援兩種罰款來源：SHOPEE_TO_US（蝦皮向我方開罰）、SHOPEE_TO_FLEET（蝦皮直接向車隊開罰）；同案可同時存在。
- 原始開罰、申訴爭議金額、蝦皮最終確認、我方承擔、車隊應負擔、實際扣款分開記錄。
- 未確認責任或申訴中的金額，不得直接列為已核准車隊扣款。
- 原始回報與歷史異動不得覆蓋或無痕刪除；更正需新增紀錄。
- 時間以 Asia/Taipei 顯示；資料庫使用 timestamptz。

## 2. 異常案件
欄位：案件編號（AB-YYYYMMDD-流水號）、發生/回報時間、車隊、路線、派車批次、車趟關聯、車牌、車型、司機姓名/工號快照、異常類型、地點、發現人、回報人、來源、事件經過、營運影響、初步處置、補救措施、改善要求、責任狀態及案件狀態。
異常類型至少包含：延遲到站、未到站、漏送、短少、錯送、貨損、車輛故障、交通事故、服務態度、違反作業規範、其他；管理端可維護。
責任狀態：待調查、我方、車隊、蝦皮、第三方、共同責任、無法判定。
案件狀態：新案件、調查中、待蝦皮回覆、待車隊回覆、申訴中、待改善、已結案、重新開案。
每次回報、補件、指派、狀態變更、責任判定及結案都新增時間軸事件，記錄操作者、時間、動作、前後值及原因。

## 3. 溝通紀錄
每筆溝通關聯案件，記錄對象類型（蝦皮窗口/車隊窗口/司機/內部/其他）、姓名、部門/職稱、日期時間、方式（電話/LINE/Email/系統/會議/其他）、主旨、我方說明、對方回覆、對方要求、承諾事項、負責人、追蹤日期、處理結果及附件。電話需記錄通話重點；口頭確認另建紀錄。

## 4. 雙向罰款
每筆罰款獨立編號，可關聯案件、車隊、車趟及路線。
欄位：罰款來源、被開罰對象、蝦皮通知編號、開罰/收件日期、違規原因、蝦皮原始認定、原始金額、幣別、通知附件、責任判定與依據、責任比例（如適用）、審核人/時間、申訴日期/內容/爭議金額、蝦皮回覆、申訴結果、蝦皮最終金額、我方最終承擔、車隊應負擔、實際扣款、扣款日期及對帳參考資料。
狀態：待資料、待核對、待申訴、申訴中、部分撤銷、全數撤銷、已確認、待扣款、部分扣款、已扣款、爭議處理中、已結案。
規則：
- 原始開罰金額不可直接覆寫；修正以調整歷程保存。
- 申訴金額不等於撤銷金額。
- 車隊應負擔金額須人工核准並記錄依據，不可自動將蝦皮罰款全額轉嫁。
- 支援分次扣款；累計扣款不得超過核准金額，例外須授權並留痕。
- 作廢須記錄原因、操作者及核准者。
- 報表分開計算原始開罰、最終金額、我方承擔、車隊應負擔、實際扣款及未扣餘額，避免重複計算。

## 5. 證據附件
支援照片、影片、PDF、Email匯出檔、LINE截圖及其他文件。記錄所屬案件/溝通/罰款、上傳者、時間、原始檔名、MIME、大小、儲存識別及雜湊值。附件採私有雲端儲存及授權存取，不以公開分享連結作唯一控管；限制檔案類型/大小並驗證上傳權限。替換以新版本或新附件保存。

## 6. 權限與稽核
dispatcher 可建立案件、補充事件/溝通、上傳證據及建立申訴草稿；admin 核准責任、車隊應負擔金額、作廢/更正及結案。所有讀寫操作記錄操作者、時間、動作及目標；金額、責任、狀態另存歷程。敏感聯絡資料依角色限制存取。

## 7. 報告與統計
案件報告包含基本資料、車趟、事件時間軸、調查處置、證據、蝦皮/車隊溝通、責任依據、罰款與申訴結果、改善及結案說明。
統計包含各車隊異常件數/類型/趨勢、兩種罰款來源分開統計、原始/最終/應負擔/實扣金額、申訴成功率及待追蹤案件。

## 8. 建議資料表
shopee_exception_cases、shopee_exception_trip_links、shopee_exception_events、shopee_exception_communications、shopee_exception_attachments、shopee_penalties、shopee_penalty_payments、shopee_penalty_history。
實作前必須檢查現有資料庫 schema 及關聯，不可猜測欄位或破壞既有資料。

## 9. 開發順序與驗收
1. 案件建立、唯一編號、車隊/車趟關聯及時間軸。
2. 溝通紀錄與附件 metadata。
3. 雙向罰款、申訴、責任核准及分次扣款。
4. 案件報告與車隊/罰款統計。
5. LINE 回報及雲端附件整合。
驗收：同案多車趟/多罰款；雙向罰款並存；金額分欄；未核准不可扣款；所有重要異動可追溯；附件有權限保護；可篩選/匯出；不得影響既有蝦皮需求、港口派車及 LINE 功能。
